# Data Sources and References

- NIST, [Atomic Spectra Database](https://physics.nist.gov/asd): source for the Na I D air-wavelength anchors used in the interface. Accessed 2026-09-26.
- IAU Resolution C1 and Lindegren & Dravins (2003), *The fundamental definition of radial velocity*, A&A 401, 1185: terminology and the distinction between spectroscopic redshift measures and geometric radial velocity.
- Bouchy, Pepe & Queloz (2001), *Fundamental photon noise limit to radial velocity measurements*, A&A 374, 733, DOI `10.1051/0004-6361:20010730`: photon-noise quality-factor relation.
- ESO, [HARPS instrument performance](https://www.ls.eso.org/lasilla/sciops/3p6/harps/performance.html): instrument context for approximately metre-per-second precision.
- ESO, [ESPRESSO overview](https://www.eso.org/sci/facilities/paranal/instruments/espresso/overview.html): configuration-specific RV precision requirements.

The repository downloads no observational spectrum. The line display is a deterministic illustration grounded by selected wavelength anchors.
