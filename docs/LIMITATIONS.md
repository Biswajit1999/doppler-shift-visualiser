# Limitations

- The one-dimensional special-relativistic equation is not a complete barycentric radial-velocity reduction and is not a cosmological redshift model.
- The spectrum is painted from stylized line depths and a visible-color background. It has no continuum radiative-transfer model, line-spread function, pixel sampling, blaze function, or detector noise.
- The wavefront animation exaggerates spacing changes for legibility and must not be measured.
- Only one telluric marker is separated by frame; real telluric absorption is a time-variable forest requiring atmospheric modelling.
- Air/vacuum wavelength conventions, barycentric corrections, gravitational redshift, convective shifts, template mismatch, and stellar activity are outside the calculator.
- The photon-noise equation supplies context only. Q and electron counts are not inferred from the illustration, so the interface does not output a precision forecast.
- The ±300 km/s slider is useful for visual displacement but is orders of magnitude broader than extreme-precision exoplanet reflex signals.
